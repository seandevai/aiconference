# Spike CPU — encode, MediaPipe, VAD nello stesso browser

Spec §11, rischio 2. Pagina: `/dev/spike-cpu` (solo `npm run dev`).

## Come si misura

1. Portatile collegato alla corrente, Chrome aggiornato, nessun'altra scheda pesante.
2. `npm run dev` nel Codespace, porta 3000 inoltrata in locale (`gh codespace ports forward 3000:3000`), apri `http://localhost:3000/dev/spike-cpu`.
3. Avvia, concedi camera e microfono, muovi le mani davanti alla camera e parla per 2 minuti.
4. Copia i risultati a 120 secondi nella tabella.
5. Ripeti con la batteria, se è il caso d'uso tipico.

## Criterio

Passa se, a 120 secondi: `outboundFps` ≥ 24, `qualityLimitation` diverso da `cpu`,
`hand.p95` ≤ 33 ms, `longTasks` ≤ 60 in totale.

Se non passa: frequenza di MediaPipe dimezzata (ARCHITECTURE §8, frequenza adattiva)
e nuova misura. Se non passa nemmeno così, ADR sul degrado delle gesture.
